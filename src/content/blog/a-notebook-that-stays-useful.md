I keep one text file per question. A title such as "Why does the print layout cut off the last line?" is easier to search for than "Print notes, Tuesday." If one question leads to another, I give the second question its own file and link the two.

## Write the result first

When I solve a problem, I put the result at the top of the file. Below it I keep the command or observation that changed my mind. I leave out routine attempts unless I expect to repeat them.

A short entry might look like this:

```text
Question: Where did the extra page come from?
Result: The footer had a minimum height in the print stylesheet.
Check: Print the same test page before and after removing that rule.
```

## Keep an index for the active work

I keep a short list of links for whatever I'm working on this week. When the project wraps up, the list can go away. The individual files stay searchable by the questions that made me write them.
